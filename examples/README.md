# Example Input Data

No real SISIP/Ministry production document or participant dataset is bundled.

To test ingestion, add your own authorized files under a Drive folder and set `GOOGLE_DRIVE_FOLDER_ID` in `.env`. Recommended test set:

- one public/synthetic PDF or DOCX with narrative material (definitions/procedures), and
- one synthetic CSV/XLSX/Google Sheet with tabular rows and clear column headers.

Use content you are permitted to publish. The ingestion workflow itself is the demonstration artifact; a private production dataset is not required in GitHub.
