# Disclaimer

This repository is a sanitized portfolio/reference implementation derived from a PKL implementation of an AI Agent Chatbot in the SISIP context. It is not an official Ministry of Tourism repository, service, release, or deployment package.

The repository intentionally excludes production credentials, OAuth tokens, n8n credential objects, database row data, private knowledge documents, WhatsApp sessions/media, production logs, and other runtime data. Any organization-specific data used in a new deployment must be supplied by an authorized operator.

Historical figures from the report are retained as documentation and may describe an earlier configuration; current supplied runtime differences are documented in `docs/known-differences.md`.
